## Como ejecutar
Descargar el ZIP

1. En la esquina superior derecha de la vista del proyecto en v0, haz clic en los **tres puntos (...)**
2. Selecciona **"Download ZIP"**
3. Extrae el ZIP en tu computadora
4. Abre la carpeta en VS Code
5. Abre la terminal integrada (Ctrl+` o Cmd+`) y ejecuta:


```shellscript
# Instalar dependencias
pnpm install

# Correr el servidor de desarrollo
pnpm dev
```

Si no tienes pnpm instalado, puedes usar npm:

```shellscript
npm install
npm run dev
```

El proyecto estará disponible en `http://localhost:3000`
